# CodeQuest

Gamified coding learning platform for engineering students.

## 🚀 Tech Stack

- **Frontend Framework:** React 19 + Vite
- **Styling:** Tailwind CSS v4
- **Animations:** Framer Motion
- **Icons:** Lucide React

## 📁 Project Structure

```
src/
├── features/
│   ├── landing/         # Landing Page
│   ├── auth/            # Authentication
│   ├── dashboard/       # Main User Dashboard
│   ├── programming/     # Programming World
│   ├── dsa/             # Data Structures & Algorithms World
│   ├── web/             # Web Development World
│   ├── topics/          # Topic Selection
│   ├── challenges/      # Coding & Quiz Challenges
│   ├── profile/         # User Profile & Stats
│   └── leaderboard/     # Leaderboard Rankings
├── components/          # Shared UI Components
├── services/            # API & Data Services
└── utils/               # Utilities & Helpers
```

## 🛠️ Getting Started

### Prerequisites

- Node.js (v18+ recommended)
- npm or yarn

### Installation

```bash
npm install
```

### Development Server

```bash
npm run dev
```

### Production Build

```bash
npm run build
```
